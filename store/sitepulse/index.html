Before you start

A few useful answers.

Does the example check my website?

No. This page only switches between sample monitoring states. Add a website in the application to run a real check.

Does SitePulse guarantee uptime?

No. SitePulse helps you inspect website checks and incidents; it cannot guarantee that a website stays online.

Can it check private or local addresses?

The monitor accepts public HTTP/S addresses and rejects private or local network targets.

Does it look up domain expiry automatically?

The current workflow supports a manually entered domain expiry date. Automated WHOIS or RDAP lookups are not represented here.
