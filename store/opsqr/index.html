Before you start

A few useful answers.

Does this page access my camera?

No. The scan button simulates opening an asset. The illustrated tag is decorative; use the button to explore the example.

What does a real QR code open?

OpsQR provides QR links to public tokenized asset reporting pages. Those pages connect a report to the relevant asset.

Is the example a real safety inspection?

No. It demonstrates checklist completion, not inspection guidance or certification. Define appropriate procedures for your actual assets.

Can I attach a photo?

The current application supports a validated photo URL. Native photo-upload storage is not claimed here.
