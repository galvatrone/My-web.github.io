Before you start

A few useful answers.

Can clients review without using the team dashboard?

Yes. The application provides tokenized client portal links for viewing project requests and deliverables, commenting and approving.

Can I upload files directly?

The current workflow uses validated file URLs for deliverables. Binary file upload storage is not part of the functionality described here.

Does the demo change a real project?

No. Approval and reset only change the illustrative project on this page.

Is this a full project management suite?

ClientDock focuses on the client-facing handoff: projects, requests, deliverables, comments and approvals.
