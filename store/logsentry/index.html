Before you start

A few useful answers.

Is this a live log stream?

This marketing demo uses a small fixed set of local events. The application accepts events through tokenized HTTPS ingestion endpoints.

Does LogSentry diagnose the root cause automatically?

No. The workflow supports event search and rule-based matching by severity or text. It does not claim automatic root-cause analysis.

How much event history is searchable?

The current application supports a seven-day event search window with retention cleanup.

Does the rule demo send an alert?

No. Testing the rule only matches text against the sample events shown on this page. Production email delivery requires a configured sender.
