Before you start

A few useful answers.

Does CronBeacon run the job for me?

No. CronBeacon tracks heartbeat check-ins. Your existing scheduler or task runner remains responsible for executing the job.

How does a task check in?

Each heartbeat job has a tokenized ping URL. Your task sends a request to that endpoint to record a check-in.

Are real alerts sent from this demo?

No. These are local sample states. Production email delivery in the application requires a configured sender.

Does a ping prove the whole task succeeded?

A ping confirms that the check-in reached CronBeacon. Place the ping at the appropriate point in your task; it is not a replacement for validating the task’s output.
