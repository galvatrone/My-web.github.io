Face Recognition

Python-программа для распознавания лиц в реальном времени с веб-камеры. Система использует OpenCV для захвата видеопотока, отрисовки рамок и интерфейса, а библиотека face_recognition на базе dlib отвечает за поиск лиц и вычисление face encodings.

Проект рассчитан на автономную работу: новые лица автоматически получают UUID, сохраняются как Unknown, получают первое фото и начальный embedding. Система ведет общую историю событий, отдельные логи по каждому человеку и умеет накапливать новые encodings для повышения устойчивости распознавания со временем.

  • Category :Computer Vision / Python
  • Stack :Python, OpenCV, face_recognition, dlib, pickle
  • Mode :Offline / Real-time Webcam
  • Data Store :known_faces.pkl + faces/<user_id>/
  • Identity Model :UUID + Auto-learning Encodings
  • Controls :q / w / d
  • Status :Portfolio Concept / Implementation Ready

Core Features

Система спроектирована как один файл с понятными функциями, чтобы код было легко переносить, запускать и дорабатывать без сложной структуры проекта.

  • Захват кадров с камеры и визуализация через OpenCV.
  • Поиск лиц и сравнение encoding через face_recognition.
  • Автосоздание нового ID и сохранение первого лица в main.jpg.
  • Попытка восстановить ID по позиции, если encoding временно не совпал.
  • Обновление профиля новыми encoding, если лицо похоже, но ракурс новый.

"Цель проекта: не просто распознать лицо в кадре, а удерживать стабильную идентичность человека между кадрами, даже если модель получает шумный или неполный embedding."

Design Note - Identity Persistence

Architecture

База известных лиц хранится в known_faces.pkl: для каждого UUID сохраняются имя, список encoding, время первого и последнего появления, а также служебные метаданные для сопоставления. При каждом кадре система получает координаты лица, считает face encoding, сравнивает его с уже известными профилями и выбирает лучшее совпадение по расстоянию. Если прямое совпадение не найдено, включается проверка по близости к недавно замеченной позиции, чтобы вернуть прежний ID при кратковременных ошибках распознавания. Время видимости считается как интервал между первым обнаружением лица в текущем сеансе присутствия и последним кадром, где это лицо еще находится в зоне видимости.

Implementation Flow

  • Загрузить базу known_faces.pkl при старте приложения.
  • Читать кадры, искать лица, вычислять coordinates и encodings.
  • Сопоставлять лицо по embedding, затем по пространственной близости.
  • Обновлять таймер присутствия и рисовать имя с временем на экране.
  • По w переименовывать ID, по d удалять запись и артефакты.

What Is Stored

  • known_faces.pkl хранит список людей и их encodings.
  • faces/<user_id>/main.jpg хранит основное фото профиля.
  • В папке пользователя могут сохраняться дополнительные снимки лица.
  • Общий лог фиксирует все события, отдельный лог ведется по каждому UUID.
  • Удаление ID очищает запись из базы, фото и связанные логи.
